** Types of Optimization
*** Cost-Based
For each possible plan it.
+ Assigns a cost
+ Sums up the total cost
+ Selects the lowest plan, known as Cost-Based Optimization(CBO)
*** Heuristic-Based
Instead of checking all possible execution plans, the DBMS  uses simple rules to quickly produce a good enough optimized plan.

Steps of Using Heuristic
+ Apply Selection (σ) early
+ Apply Projection (π) early
+ Perform Highly selective operations first
+ Reorder joins to avoid Cartesian products
+ Combine cascading selections (merge item)
 σ condition (σ condition2 (R)) ----> σ(condition1 AND condition2) (R) ------Avoids multiple scans and reduces work.

** Scalar subquery
A scalar Subquery is a subquery that returns exactly one row and one columnm(a single value)

Syntax
#+begin_src sql
SELECT columns
FROM table
WHERE column = (subquery returning one value);
#+end_src


Example
#+begin_src sql
SELECT name, marks FROM students
WHERE marks = (
      SELECT MAX(marks) FROM students
)
#+end_src

*** Row Subquery
A rwo subquery returns one row, but it can contain multiple columns.
** Multi-row subquery
A multi row subquery returns more than one row. (IN,ANY,ALL)

1. IN ----> match valeus returned by a subquery.
#+begin_src sql
SELECT columns FROM table
WHERE column IN (subquery);
#+end_src

2. ANY ---> ANY compares with any one value returned by the subquery.
   marks > ANY(92,60) becomes marks > 60.
#+begin_src sql
SELECT columns FROM table
WHERE column > ANY (subquery);
#+end_src

3. ALL ---> Compare with all values returned by subquery.
   marks > {85, 75} ----> marks > 85.
#+begin_src sql
SELECT columns FROM table
WHERE column > ALL (subquery);
#+end_src

** Correlated subquery
+ Its commonly used when we have two tables
+ When a two tables have some common columns in it.We can check if each row of parent is following some condition in the child table
- Each subquery is executed once for every row of the outer query.

*** Example
Find students whose marks are above the average of thier department
#+begin_src sql
SELECT columns FROM table alias1
WHERE column > (
      SELECT .... FROM table alias 2
      WHERE alias2.col = alias1.col
);
#+end_src

#+begin_src sql
SELECT s1.name, s1.marks FROM students s1
WHERE s1.marks > (
      SELECT AVG(s2.marks)
      FROM students s2
      WHERE s2.dept_id = s1.dept_id
);
#+end_src
