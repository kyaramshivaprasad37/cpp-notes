 Represents relation b/w attributes in a relatinal database.
 X uniquely determines Y ------> Y is said to be functional dependent on X (X -> Y)
* Rules of Functional Dependency
- Augmentation
  X -> Y then XZ -> YZ
- Transitive
  X -> Y and Y -> Z then X-> Z
* Types of Functional Dependency
1. Trivial functional Dependency
   Y ⊆ X then: X -> Y (Trival FD)
   (product_id, stock_count) -> product_id
2. Non-Trival functional dependency
   A non-trival FD means that the dependent attribute is not part of the determinant. So it gives new information
   Y ⊄ X Then X -> Y (Non -trival FD)
