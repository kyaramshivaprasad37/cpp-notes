* DEFINATION
:PROPERTIES:
:ID:       4be5e117-36a4-4299-8c59-2e0d8fa1b405
:END:
- A VIEW works like a virtual table created using a SQL query.
- It does not store data itself but displays data from one or more tables.
* Syntax
:PROPERTIES:
:ID:       ae483cfe-46eb-48cf-bc53-8a3e09a42c94
:END:
#+begin_src sql
CREATE VIEW view_name AS
SELECT column1, cloumn 2, ...
FROM table_name
WHERE condition;
#+end_src
* CREATE OR REPLACE view
:PROPERTIES:
:ID: CREATE OR REPLACE
:END:
- replacing a VIEW allows us to change the defination of an existing view without deleting it.
- This is useful when you want to update the columns shown or adjust the filtering conditions while keeping the view name,
  permissions and dependent objects unchanged.
** Syntax
#+begin_src sql
CREATE OR REPLACE view_name AS
SELECT column1, column2,..
FROM table_name
WHERE condition;
#+end_src
* DROP VIEW
:PROPERTIES:
:ID: DROP VIEW
:END:
#+begin_src sql
DROP VIEW IF EXISTS view_name;
#+end_src

:PROPERTIES:
:ID: ALTER View - Renaming a View
