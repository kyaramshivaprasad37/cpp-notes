* Identity Columns (Auto-Increment)
#+begin_src sql
CREATE TABLE table_name (
column_name INT GENERATED {ALWAYS | BY DEFAULT} AS IDENTITY
(START WITH n INCREMENT BY n)
);
-- ALWAYS: Overrides user input
-- BY DEFAULT: Uses identity unless value provided manually
#+end_src

    Specialized Constraints
    ** Unique and Alternate Keys
    #+begin_src sql
    -- Inline Unique
    CREATE TABLE table_name (
    column_name data_type UNIQUE,
    column_name data_type DEFAULT default_value
    );

-- Composite Unique (Alternate Key)
CREATE TABLE table_name (
column1 data_type,
column2 data_type,
UNIQUE (column1, column2)
);
#+end_src

* Check Constraints
#+begin_src sql

#+end_src

    Referential Integrity (Foreign Keys)
    Defining how data relates between tables and how to handle deletions/updates.

* Foreign Key Syntax
#+begin_src sql
CREATE TABLE table_name (
column_name data_type,
FOREIGN KEY (column_name) REFERENCES parent_table (parent_column)
ON DELETE action_name
ON UPDATE action_name
);
#+end_src

* Actions for ON DELETE / ON UPDATE
These define what happens to the "child" row when the "parent" row is changed or removed:

    CASCADE: Automatically delete or update the child rows.

    SET NULL: Sets the child foreign key column to NULL.

    SET DEFAULT: Sets the child foreign key to its default value.

    RESTRICT: Prevents the change/deletion of the parent row if children exist.
